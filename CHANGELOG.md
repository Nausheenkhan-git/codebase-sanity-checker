\# Changelog



All notable changes to this project will be documented in this file.



\## \[1.0.0] - 2026-08-30



\### Added

\- Initial release of Codebase Sanity Checker

\- Repository cloning functionality

\- Structure analysis (files, directories, Python files)

\- Test execution with pytest

\- Linting with flake8

\- Dependency checking (requirements.txt, setup.py, pyproject.toml)

\- Quality scoring system (0-100 with breakdowns)

\- Actionable recommendations generation

\- Markdown report generation

\- JSON output for data analysis

\- Baseline vs advanced comparison

\- Batch testing script

\- Comprehensive documentation



\### Technical Features

\- Python 3.8+ support

\- Virtual environment support

\- Automatic cleanup of cloned repositories

\- Error handling and timeout protection

\- Structured output formatting
